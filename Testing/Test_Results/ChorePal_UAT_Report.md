## 2. Summary of Testing Process

**When:** UAT was conducted on October 1st and 8th, 2026. We had Team 1 and Team 3 test our mobile application by
giving them two devices, one acting as the parent device and the other as the child device.

**Where:** Testing was performed in the classroom by different team members using our personal devices.

**How:** We had other teams act as both the Parent and Child users. Their testing covered account creation, authentication,
creating chores/rewards, chore submission using ChorePal verification, parent approval/rejection, rewards, and logging
out. With Team 3 testing a week before Team 1, we made sure all issues presented in Team 1 were fixed and retested by
Team 3.

## 4. Defect Log

All defects discovered during earlier peer testing and internal QA were resolved prior to formal UAT. The table below
records those defects and their final resolution status for traceability. No new defects were identified during UAT
execution.

| Defect ID | Description | Severity | Status | Resolution |
|---|---|---|---|---|
| DEF-01 | The child reward page balance was not updating properly. | Minor | Resolved | We added a refresh button. |
| DEF-02 | Chore Priority setting did not work. It would not affect chores on the child dashboard in any way. | Minor | Resolved | Updated child dashboard to sort chores by priority. |
| DEF-03 | The logout button was difficult to find. | Cosmetic | Resolved | Although the button previously worked, it was difficult for users to locate. We made it much easier to find. |
| DEF-04 | The whole chore on the child dashboard was not clickable, as only the small upload button was clickable. | Minor | Resolved | We made the entire chore card clickable. |
| DEF-05 | Chores were not assigned to the correct date. | Major | Resolved | Fixed the date filtering so that it would assign chores on the correct dates. |
| DEF-06 | Chore deadlines were not saved correctly and the calendar was always a day behind. | Critical | Resolved | We fixed the calendar as well as the deadlines showing up correctly. |
| DEF-07 | The parent dashboard did not have a way to click on child accounts to edit or view their family code. | Major | Resolved | We added a child details page that, when clicked, allows you to see a copyable family code as well as edit child accounts. |
| DEF-08 | No maximum limit on coins when creating chores and rewards. They were able to set a chore that gave a million coins. | Minor | Resolved | We added max-coins validation on chore creation and reward creation. |
| DEF-09 | Parent feedback was not being sent to the children. | Major | Resolved | Feedback is now visible to the child by clicking on the chore that was approved/rejected. |
| DEF-10 | The keyboard was blocking the description and feedback input fields. | Cosmetic | Resolved | We adjusted the app layout so it wouldn't block the feedback/description input fields. |
| DEF-11 | Forgot Password flow did not work on the login page. | Minor | Resolved | Password-reset flow is now implemented in our app and sends an email to reset your password when requested. |

**Conclusion:** We resolved all defects that were found in the first and second UAT.
